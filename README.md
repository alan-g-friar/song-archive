# Song Archive

Author: Alan G. Friar  
Started: 1-April-2026  

---

## Overview

This repository contains original songs written as part of a personal project, which may develop into an annual tradition.

Each song captures a specific moment, realization, or period of life.

These works are not structured as publications or technical outputs, but as reflections expressed through music.

---

## Structure

Songs are organized by year.

Each song folder contains:
- README (context and meaning)
- Lyrics
- Style prompt
- Cover artwork
- Audio versions (examples - free, pro, final)

---

## Rights

All lyrics are original works authored by Alan Gonzaga Friar.

Audio files are generated using Suno:
- "free" versions: non-commercial reference
- "pro" versions: commercially usable
- "final" versions: selected official recordings

---

## Notes

These songs are independent works and are not part of any other publication or framework.
